 Do not forget to add extern "C" before the function itself. It returns a new instance allocated with new: Arcade::IGame * for a game library, Arcade::IGraphics * for a graphics library. The core takes ownership of it and deletes it before closing the library. A raw pointer is used because a C++ class such as std::shared_ptr cannot cross an extern "C" boundary safely.
